# Campus Asset Tracking System

A web-based Campus Asset Tracking System developed to manage and monitor institutional assets efficiently.

## Project Overview

The system helps manage campus assets, track their assignments to employees, monitor maintenance activities, and view asset availability through a centralized dashboard.

## Technologies Used

- PHP
- Microsoft SQL Server
- HTML5
- CSS3
- XAMPP
- Visual Studio Code

## Main Features

- Dashboard displaying asset statistics.
- Add and view campus assets.
- Assign assets to employees.
- Track asset assignments and returns.
- Manage maintenance records.
- Monitor asset availability and status.

## Database

Database Name: `CampusAssetDB`

The application uses Microsoft SQL Server for storing and managing asset information.

## Installation and Setup

1. Install XAMPP and Microsoft SQL Server.
2. Clone or download this repository.
3. Place the project folder inside `C:\xampp\htdocs\`.
4. Create the database named `CampusAssetDB`.
5. Import or execute the required database SQL scripts.
6. Configure your local database connection using `db_connect.php`.
7. Start Apache through XAMPP.
8. Open the project in your browser:

   `http://localhost/CampusAsset/`
